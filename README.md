# امداد یار — برنامک ایتا برای امداد و نجات

راهنمای گام‌به‌گام کمک‌های اولیه، شماره‌های اضطراری، ساخت پیام درخواست امداد همراه با موقعیت مکانی، چک‌لیست اقدامات صحنه و آزمون آموزشی؛ با دو حالت **عمومی** و **امدادگر**.

- React 18 + TypeScript + Vite 6
- PWA (نصب روی صفحه اصلی + کش آفلاین)
- راست‌به‌چپ فارسی، فونت وزیرمتن، اعداد فارسی
- موشن‌گرافیک آموزشی SVG برای مراحل حیاتی (CPR، هایملیک، ضربه بین کتف، وضعیت بازیابی، فشار خونریزی، خنک‌سازی سوختگی و آتل) + پخش ویدیوی آموزشی رسمی هلال احمر/اورژانس ۱۱۵ داخل همان صفحه
- اتصال به کیت توسعه ایتا (Eitaa WebApp SDK)

> این برنامک ابزار آموزشی است و جایگزین آموزش رسمی کمک‌های اولیه یا تماس با اورژانس نیست.

## اجرای محلی

پیش‌نیاز: Node.js 18 یا بالاتر.

```bash
npm install
npm run dev
```

آدرس: http://localhost:5173 — برای تست روی گوشی در همان شبکه، آدرس Network خروجی Vite را باز کنید.

نکته: موقعیت‌یابی در مرورگر فقط روی `localhost` یا HTTPS کار می‌کند.

## بیلد و پیش‌نمایش تولید

```bash
npm run build     # بررسی نوع‌ها + ساخت خروجی در پوشه dist
npm run preview   # پیش‌نمایش خروجی نهایی
```

## استقرار (هاست HTTPS)

برنامک ایتا فقط با آدرس **HTTPS و بدون ریدایرکت** باز می‌شود. خروجی `dist` را روی هر هاست استاتیک بگذارید:

- **Vercel**: پروژه را وصل کنید؛ Build Command: `npm run build` — Output: `dist`
- **Netlify**: همان تنظیمات؛ پوشه انتشار: `dist`
- **GitHub Pages**: خروجی `dist` را در شاخه `gh-pages` قرار دهید (base پروژه در `vite.config.ts` روی `./` تنظیم است)

بعد از استقرار، همان لینک HTTPS را در فیلد «آدرس دکمه» ثبت برنامک وارد کنید.

## ثبت برنامک در ایتا («برنامک من»)

از حساب رسمی، در پنل مدیریت ایتا بخش «برنامک من» را باز کنید (یا برای دریافت دسترسی به `myminiapp_app@` پیام بدهید) و این مقادیر را وارد کنید:

| فیلد | مقدار پیشنهادی |
|---|---|
| تصویر برنامک | `public/icon.svg` (یا خروجی PNG مربعی ۵۱۲×۵۱۲) |
| نام | امداد یار |
| نام کاربری | `emdadyar_app` (پسوند `_app` الزامی است) |
| توضیح کوتاه | همراه دقایق طلایی؛ کمک‌های اولیه، شماره‌های اضطراری و درخواست امداد |
| عنوان دکمه | باز کردن |
| آدرس دکمه | لینک HTTPS پروژه (بدون ریدایرکت) |

پس از تأیید، برنامک داخل ایتا باز می‌شود؛ دکمه بازگشت ایتا در صفحات داخلی فعال و در صفحه اصلی پنهان است.

## ساختار پروژه

```
src/
  content/        داده‌های آموزشی: راهنماها، شماره‌ها، آزمون، چک‌لیست
  screens/        صفحات (خانه، راهنماها، شماره‌ها، درخواست امداد، چک‌لیست، آزمون، درباره)
  components/     آیکون‌ها، توست، زمان‌سنج CPR
  lib/            روتر هش، اتصال ایتا، حالت نمایش، ذخیره‌سازی محلی، اعداد فارسی
  styles.css      سیستم طراحی (توکن‌های رنگ، کارت، دکمه، فاصله‌های ایمن دستگاه)
public/icon.svg   آیکون برنامک
```

## نکات فنی

- اسکریپت `https://developer.eitaa.com/eitaa-web-app.js` باید در `<head>` و پیش از بقیه اسکریپت‌ها باشد و به‌صورت محلی ذخیره نشود.
- `initData` را در صورت نیاز به احراز هویت، فقط در سرور اعتبارسنجی کنید؛ در این نسخه داده‌ای به سرور ارسال نمی‌شود.
- متن «درخواست امداد» به‌صورت خودکار ارسال نمی‌شود؛ کاربر آن را در چت ایتا به اشتراک می‌گذارد.
- داده‌های کاربر (حالت نمایش، چک‌لیست، بهترین نتیجه آزمون) فقط در `localStorage` دستگاه ذخیره می‌شود.
- موشن‌گرافیک‌ها با SVG و CSS خالص (بدون کتابخانه اضافه) ساخته شده‌اند و در صورت فعال بودن `prefers-reduced-motion` سیستم، متوقف می‌شوند.
- لینک ویدیوهای آموزشی در `src/content/videos.ts` تعریف شده‌اند و با پلیر تعبیه‌شده (iframe) آپارات داخل همان صفحه پخش می‌شوند؛ گزینه «پخش در آپارات» هم به‌عنوان جایگزین موجود است. محتوای ویدیوها میزبانی داخلی نیست و در دسترس بودنشان به آپارات بستگی دارد.
